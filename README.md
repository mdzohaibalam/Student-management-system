# Student Management System

A simple Student Management System project developed by a BCA student using HTML, CSS, and JavaScript.

## About the Project

The Student Management System is a beginner-friendly web application designed to manage basic student information. It allows users to add student details and display them in an organized table.

## Features

- Add new student details
- Enter student name, roll number, and course
- Display students in a table
- Prevent duplicate roll numbers
- Delete student records
- Display the total number of students
- Simple and responsive user interface

## Technologies Used

- HTML – Structure of the website
- CSS – Styling and layout
- JavaScript – Functionality and student record management

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser.
4. Enter the student name, roll number, and course.
5. Click the **Add Student** button to add a record.
